# Normality Check

This folder contains SAS and R outputs, validation tables, and supporting documentation for comparison of normality tests.

How to use the available information to validate the differences manually.

For each type of procedure/test/model two branches will be created on under the main branch one for SAS and one for R.

Similar outputs will be created for both programs. 

As described in each individal branch in detailes - you would need to download all the information related to your computer and follow the instruction of running both SAS and R.
